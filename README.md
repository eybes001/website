# Eyad Beshier — Lumen Studio

Original free-hostable interactive portfolio website, with a cinematic introduction, independent demonstrations, and a true 3D GLB office environment. No people or avatar appear in the visuals or the room model.

## What's here

- **Verified static edition (primary)**: `index.html`, `style.css`, `app.js`, `scene.js`, `site.config.json` + `public/` media. No npm install required. The static version is the one tested and ready for immediate hosting.
- **3D model**: `public/models/studio.glb` — an original ~197 KB scene generated from `scripts/generate_studio.py`, with 251 modeled parts and uniquely named monitor and gallery targets. Uses no third-party 3D assets.
- **React/TypeScript + React Three Fiber edition (source)**: `index.react.html`, `src-react/`, `vite.react.config.ts`. An alternative implementation; its package installation/build could **not** be verified in the restricted environment because npm registry access is blocked. Not the default production deployment.
- **Deployment files**: `dist/` generated by `python3 scripts/build_static.py` and `render.yaml`.
- **QA scripts and browser screenshots**: `tests/`.

## Run the tested static edition

From the repository root:

```sh
python3 scripts/build_static.py
python3 -m http.server 8080 --directory dist
```

Then visit http://localhost:8080.

The 3D room needs a connection to the Three.js CDN and WebGL to run. Every portfolio section, demo, and contact navigation remains usable **without** the 3D renderer. The cinematic introduction is an image, while the separately entered studio is a real 3D GLB environment; these are deliberately distinct.

## Deploy to Render (static site)

1. Commit the project into a dedicated repository or isolated branch. **Do not blindly overwrite an existing deployed portfolio.**
2. On Render create a **Static Site** linked to that repository and branch.
3. Build command: `python3 scripts/build_static.py`
4. Publish directory: `dist`
5. Add your existing domain only once the new preview meets your expectations.

Hosting of the static output is eligible for Render's free static hosting offering, subject to its current plan limits. A custom domain is optional. No database or paid API is required.

## Optional React/TypeScript implementation

This is supplied to support a future maintainable React Three Fiber build. It has the same conceptual architecture (3D GLB loader, guided views, portfolio, and controlled analytics), but was **not** browser-built here:

```sh
npm install
npm run dev:react
npm run build:react
```

The alternative React output is `dist-react/`. Before choosing it for production, run type checks, validate the bundle and retest all interactions. The primary `dist/` is the validated deployment artifact.

## Content and confidentiality

Set `publicEmail`, `linkedInUrl`, `resumePdf`, `githubUrl` in `site.config.json` before a professional launch. Missing email/LinkedIn values are omitted rather than invented. CV dates and achievements are deliberately limited to details supplied by the portfolio owner. The site has no analytics trackers or backend.

All business names and figures are **synthetic demonstration data**, not examples sourced from an employer or clients. The pricing simulator's 1.25x demand-response multiplier is an explicit pedagogical assumption, not a validated price elasticity or forecast. Do not describe its calculations as real results.

The cinematic hero was generated for this portfolio. The exterior skyline texture is from an earlier user-approved generated workspace asset. Geometric studio parts are produced by `scripts/generate_studio.py` using trimesh (no imported external furniture assets).

## 3D studio details

Interaction IDs within the model: `analyticsMonitor_Display`, `experienceFrame_Display`, `cvFrame_Display`, `biographyFrame_Display`, `contactObject_Display`. Pointer clicks open the appropriate portfolio panel. The scene's camera presets are Entrance, Desk, Gallery, Lounge and Window. Orbit is constrained and interpolated smoothly between presets.

The real-time 3D geometry is **not photorealistic hand-modeled furniture**. Most of the visual richness on the landing page comes from the cinematic illustration. The independently modeled GLB scene includes architectural elements and original procedural furniture but still needs validation on a WebGL-enabled device before calling it a final luxury-archviz implementation.

## Quality checks performed

- Generated and round-trip loaded `studio.glb` using trimesh; 251 geometries, with valid extents and required interaction names.
- JavaScript parsed successfully with `node --check`.
- Static production build completed successfully with Python.
- Inline-content browser tests passed in Chromium at widths 1440, 768, 390, and 320 pixels, testing initial dashboard, multiple business/period filters, workflow, data-quality review, and modal close. No observed JS page errors or horizontal overflow.
- The test browser blocks local and external navigation, so CDN-sourced Three.js modules, hosted WebGL scene rendering and live deployment **were not independently verified**. Do not claim those steps were completed.
